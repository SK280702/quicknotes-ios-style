QuickNotes 1.0.0 brings an iOS-style reminders experience to Android: smart lists, colored custom lists, subtasks, flags, tags, priorities, repeating due dates, and multiple photo/file attachments.

Google Drive file sync carries reminders and attachments together. Use the cloud button to create a file in Drive; connect the same file on another device. Sync also runs after saves and when returning to the app. Android 8+.

This is the first release. Model and UI tests and signed APK verification are included. Native notifications and Drive round trips require testing on a signed-in Android device. It does not implement every iOS Reminders feature. Read spec.md for sync behavior and limits.
