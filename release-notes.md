QuickNotes 1.2.0

- Swipe reminders left to reveal Details, Flag, Delete. A second left swipe or a full left swipe deletes the reminder and its subtasks.
- Tap a reminder to edit its title and notes inline. The quick bar offers date, location, tags, flag, and photos, plus time, urgent, and repeat controls once a date is set.
- Quick date/time presets, dedicated date/time/urgent/repeat/early-reminder editor, and custom hourly-to-yearly recurrence with weekday/date selections or ordinal weekdays.
- Completing a repeating reminder keeps the completed record and creates its next occurrence immediately with a different ID. Subtasks and photos travel to the next occurrence.
- Drag lists and reminders without Edit. Reminders float while dragging, snap back if no valid target exists, and become subtasks when dropped in another reminder's center. Inline Add Subtask is available.
- Only images can be newly attached. Tap photos for an in-app preview; close or Back dismisses it.
- Urgent and normal notifications show the reminder title and notes, with Dismiss and Mark As Completed. Urgent lock-screen controls use those same actions. Urgent alarms still ring with a fallback tone.
- Past urgent times display an error and reset to the current minute. New top-right … menu contains Edit and Sync Settings.
- Arrival/departure location reminders with radius from 330 ft to 150 miles. Address search/current-location selection and a Google Maps picker with a draggable blue radius circle. Embedded Google Maps requires a user-supplied Maps JavaScript API key; location access must be enabled. Keys stay on the device.

Android 8+. Signed with the existing release key, so this updates 1.0.0/1.1.0. Google Drive file sync remains supported. See spec.md for setup, OS permissions, and validation limits. Release publishing requires model, UI, Android native tests, and source/APK matching checks.
